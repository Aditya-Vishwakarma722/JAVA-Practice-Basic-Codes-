# 📚 Stack

> This folder contains my practice problems based on the **Stack data structure in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- LIFO (Last In, First Out)
- Push and Pop operations
- Peek operations
- Stack traversal
- Matching and balancing elements
- Remembering previous states
- Using Stack in problem solving
- Stack-based algorithmic techniques

---

### 🎯 Purpose

The goal of this folder is to understand when and why a Stack is useful and develop the ability to recognize problems that require LIFO behavior.

> **Last In → First Out**
