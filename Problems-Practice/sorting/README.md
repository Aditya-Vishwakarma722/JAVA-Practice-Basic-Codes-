# ↕️ Sorting

> This folder contains my practice problems based on **Sorting algorithms and techniques in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- Sorting fundamentals
- Comparing elements
- Swapping elements
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- In-place sorting
- Sorting-based problem solving
- Time and space complexity

---

### 🎯 Purpose

The goal of this folder is to understand how sorting works and learn when sorting can be used to simplify or optimize a problem.

> **Compare → Arrange → Optimize**
