# 🚶 Queue

> This folder contains my practice problems based on the **Queue data structure in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- FIFO (First In, First Out)
- Enqueue and Dequeue operations
- Adding and removing elements
- Queue traversal
- Processing elements in order
- Breadth-First Search (BFS)
- Level-based processing
- Queue-based problem solving

---

### 🎯 Purpose

The goal of this folder is to understand when a Queue is useful and become comfortable solving problems where elements need to be processed in the order they arrive.

> **First In → First Out**
