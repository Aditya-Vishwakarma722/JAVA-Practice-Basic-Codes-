# 🔍 Searching

> This folder contains my practice problems based on **Searching techniques and algorithms in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- Linear Search
- Binary Search
- Searching in sorted data
- Search boundaries
- Left and right pointers
- Midpoint calculation
- Reducing the search space
- Efficient searching techniques

---

### 🎯 Purpose

The goal of this folder is to understand different searching techniques and learn how to recognize when an efficient search strategy can be applied to a problem.

> **Search → Reduce the possibilities → Find the answer**
