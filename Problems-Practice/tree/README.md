# 🌳 Trees

> This folder contains my practice problems based on **Trees and Binary Trees in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- Tree nodes
- Binary Trees
- Binary Search Trees
- Tree traversal
- Inorder traversal
- Preorder traversal
- Postorder traversal
- Level-order traversal
- DFS
- BFS
- Recursion with Trees
- Stack and Queue based Tree problems

---

### 🎯 Purpose

The goal of this folder is to understand hierarchical data structures and learn how to navigate, traverse, and solve problems involving Trees.

> **Understand the structure → Traverse the tree → Solve the problem**
