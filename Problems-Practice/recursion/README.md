# 🔁 Recursion

> This folder contains my practice problems based on **Recursion and recursive problem solving in Java**.

---

### 📌 Focus

The problems here are used to practice and understand:

- Recursive function calls
- Base cases
- Recursive cases
- Breaking problems into smaller problems
- Call stack
- Recursive traversal
- Backtracking
- Recursive problem solving

---

### 🎯 Purpose

The goal of this folder is to develop a better understanding of recursion and learn how larger problems can be broken down into smaller, repeatable subproblems.

> **Break it down → Solve the smaller problem → Build the answer**
